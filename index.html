03Solution

Industrialize the evaluation environment, not the report.

What an evaluation environment has to beTwo properties

Independent

An optimizer cannot falsify “feasible in my model.” The check has to run somewhere the plan was not written.

Run inside its own model, a plan is always feasible. Run inside a model it did not build, it either held or it did not hold.

The submitter pays, as they do for every audit — but may not scope it, tune it, preview it, or pay only if it passes.

High-fidelity

Every plan is optimal inside the environment it was built in — and that environment is simpler than the depot.

Ours carries what the plan’s model leaves out: queueing, charge taper, tariff time structure, day-to-day variation.

A solver absorbs uncertainty in the coefficients it has, never a mechanism it never contained. When the policy is learned, you cannot read that environment at all.
