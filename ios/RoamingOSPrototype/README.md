# RoamingOS SwiftUI Prototype

This folder contains a native SwiftUI implementation of the iOS app UI shown in the reference image.

## Included screens

- Home dashboard
- Plan selection
- Schedule timeline
- Trip detail
- Trip summary
- Profile

## Quick start in Xcode

1. Open `ios/RoamingOSPrototype.xcodeproj`.
2. Select the `RoamingOSPrototype` scheme.
3. Run it on an iPhone simulator.

The app entry point is `RoamingOSApp.swift`, and the main UI lives in `RoamingOSPrototype.swift`.
